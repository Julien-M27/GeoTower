Priorites de correction:

P0 - A corriger en premier

1. Android Auto HostValidator trop permissif
Fichier: app/src/main/java/fr/geotower/car/GeoTowerCarAppService.kt
Symptome: createHostValidator retourne HostValidator.ALLOW_ALL_HOSTS_VALIDATOR alors que le service est exporte.
Risque: un host non autorise peut se connecter au CarAppService; non conforme production.
Correction attendue:
- Garder ALLOW_ALL_HOSTS_VALIDATOR uniquement si BuildConfig.DEBUG.
- En release, utiliser HostValidator.Builder(context).addAllowedHosts(androidx.car.app.R.array.hosts_allowlist_sample).build(), ou une allowlist equivalente officielle.
- Ajouter un test ou au minimum un commentaire court expliquant le mode debug/release.

2. Etat Compose mute hors thread UI
Fichiers:
- app/src/main/java/fr/geotower/ui/components/DatabaseDownloadCard.kt
- app/src/main/java/fr/geotower/ui/screens/MapScreen.kt
- app/src/main/java/fr/geotower/ui/screens/CompassScreen.kt
Symptome: des variables Compose sont modifiees dans withContext(Dispatchers.IO) ou withContext(Dispatchers.Default).
Risque: crash snapshot, comportement instable, jank.
Correction attendue:
- Faire les calculs lourds en IO/Default.
- Retourner un objet resultat immutable.
- Assigner les mutableState uniquement apres retour sur Main.

3. OSMDroid manipule hors main thread
Fichier: app/src/main/java/fr/geotower/ui/screens/MapScreen.kt
Symptome: creation de Marker, Drawable, BitmapDrawable ou acces MapView depuis Dispatchers.Default.
Risque: crashes aleatoires, fuites, incoherences UI.
Correction attendue:
- Background: calcul de specs pures seulement.
- Main thread: creation des markers, drawables lies au contexte, ajout/retrait d'overlays.
- Eviter de lire map.zoomLevelDouble depuis un thread background.

4. Permission location manquante avant enableMyLocation
Fichier: app/src/main/java/fr/geotower/ui/screens/MapScreen.kt
Symptome: enableMyLocation() appele sans verifier ACCESS_FINE_LOCATION ou ACCESS_COARSE_LOCATION.
Risque: SecurityException apres revoke permission ou comportements OEM.
Correction attendue:
- Verifier fine/coarse avant toute activation de MyLocationNewOverlay.
- Afficher un CTA permission si necessaire.
- Ne pas activer l'overlay si permission absente.
